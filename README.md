# 🏔️ 메아리 (Meari) AI
> **수학여행 산악 조난 긴급 구조 & 학교 현장 안심 관제 플랫폼**  
> *울산 AI 해커톤 출품작 | 대상 지형: 한라산 국립공원 (성판악 코스, 해발 1,950m)*

---

## 📌 1. 프로젝트 배경 및 기획 의도

* **탐구 주제 연계**: 
  - **주제 3: 존중과 배려로 함께 안심하는 학교** (어려움이 있을 때 안심하고 도움을 요청할 수 있는 방안)
  - **주제 1: 소통과 공감으로 서로 이해하는 학교** (사고 발생 시 신속하고 정확한 정보 공유로 교직원-학생-가정 간 신뢰 구축)
* **문제 상황**:  
  수학여행 및 현장체험학습 중 울창한 산악 지형(한라산 등)에서 학생이 기상 악화(짙은 안개, 비)나 대열 이탈로 **조난**당하는 사고가 빈번히 발생합니다.  
  통신이 두절되거나 학생이 당황하여 정확한 위치를 설명하지 못할 때 골든타임을 놓치기 쉽고, 이 과정에서 학교와 학생 간에 극심한 불안과 위험이 고조됩니다.
* **해결책**:  
  산악 통신 음영 지역에서도 작동하는 **오프라인 GPS/센서 추적**과, 학생이 주변에 보이는 팻말/환경을 말하면 위치를 좁히는 **음성 랜드마크 분석 AI**, 그리고 119 구조대 및 인솔교사가 신속히 대응할 수 있는 **교사 통합 관제탑**을 결합했습니다.

## ✨ 2. 핵심 기능

### ① 통신 불안정/음영 지역 극복 (오프라인 GPS & 환경 센서)
* 통신망(LTE/5G)이 두절되어도 위성 신호를 직접 수신하는 기기 내장 센서를 통해 **고도(Altimeter), 나침반 방위각(Compass), GPS 좌표**를 연속 측정.
* 전파가 닿지 않는 동안 로컬 스토리지에 궤적(Breadcrumbs)을 오프라인 축적하고, 간헐적 통신 재연결 시 1KB 미만 초경량 패킷으로 서버에 자동 싱크.
* 스마트폰 방전 방지를 위한 비상 절전 모드 지원.

### ② 음성 랜드마크 AI 위치 특정 엔진 (Voice-to-Landmark AI)
* 학생이 주변 환경(예: *"앞에 해발 1500미터라고 적힌 팻말이 보이고 대피소 건물이 있어요"*)을 음성으로 제보하면 자연어 분석을 수행.
* 한라산 5대 탐방로 정밀 지형 데이터와 대조하여 **정밀 수색 추천 반경(예: 반경 35m)과 좌표를 특정**.
* 소방청 및 인솔교사에게 맞춤형 긴급 행동 가이드 자동 제공.

### ③ 실시간 듀얼 관제 시스템 (학생 SOS 모드 - 교사 관제탑)
* **학생 SOS 모드**: 원클릭 SOS, 고주파 호루라기(2800Hz Web Audio), 야간 화면 점멸 비콘, 4대 산악 생존 요령.
* **교사 관제탑**: 전체 학급 실시간 상태판, 조난 학생 붉은 펄스 맵, 119 산악구조대 원클릭 정밀 좌표 전송.

## 🛠️ 3. 기술 스택

* **Framework**: Next.js 14 (App Router), React 18, TypeScript
* **Styling**: Tailwind CSS (산악·응급 테마, 글래스모피즘, 레이더 펄스 애니메이션)
* **Map & Geospatial**: Leaflet Interactive Map (한라산 등고선 및 실시간 수색 반경)
* **Speech & AI**: Web Speech Recognition API (한국어 STT), 랜드마크 시맨틱 매칭 AI 엔진
* **Audio**: Web Audio API (외부 파일 없는 고주파 구조 호루라기 & 모스부호 SOS 신디사이저)
